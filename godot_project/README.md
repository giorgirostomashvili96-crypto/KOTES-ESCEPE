## 🎮 როგორ გავუშვათ Godot Engine-ში

1. ჩამოტვირთეთ **Godot 4.2+ ან Godot 4.3** (უფასოა): [https://godotengine.org/download](https://godotengine.org/download).
2. გახსენით Godot -> დააჭირეთ **Import**.
3. აირჩიეთ ამ საქაღალდის `project.godot` ფაილი -> **Import & Edit**.
4. დააჭირეთ **F5** (ან ზედა მარჯვენა სამკუთხედ Play ღილაკს) — თამაში გაეშვება!

---

## 📱 როგორ მივიღოთ Android APK

1. Godot-ის მენიუში: `Project -> Export...`
2. აირჩიეთ **Android** (პროექტი უკვე წინასწარ გამზადებულია `export_presets.cfg`-ით: `com.kote.escape`).
3. დააჭირეთ **Export Project...** -> შეინახეთ როგორც `KoteRunner.apk`.
4. გადაიტანეთ Android ტელეფონზე და გახსენით!
